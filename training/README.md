# training/: everything that produces the models of the editor (private)

Nothing here is shipped. The public application is `app/`; the only bridge is `export_app.py`, which writes `app/model/`.

| path | content |
|---|---|
| `worlds/diagram/` | the diagram world at Level 1: generator, normalizer table, noise generators, paraphrase pipeline, paragraph and script generators, the LLM-author protocol |
| `worlds/textedit/` | the dictation world (spec 14) |
| `worlds/matheditor/` | the formula world (spec 16) |
| `worlds/animation/` | the temporal world (spec 19) |
| `worlds/scene/` | the scene world and the positions-as-addresses experiment (spec 17.3) |
| `data/` | frozen datasets of our own worlds, gzip with `MANIFEST.json` (sha256 of every uncompressed file); `data/unpack.py` restores a world folder and checks it |
| `parity/` | the reader's parity test, Python against JavaScript (`run_all.sh`) |
| `gpu_diagram_step3.sh` | step 3 on the DGX: the diagram world at four sizes, five seeds |
| `export_app.py` | a trained model to `app/model/<world>/` and `app/model/index.json` |
| `TODO_DGX.md` | everything that must run on the DGX, in order, with commands and exit checks |

## Data rules

- Only data generated by our own generators is committed (`data/`), frozen, with its manifest. A dataset is regenerated only by a
  deliberate change of its generator, recorded in the commit and in `data/README.md`.
- Data that comes from others (public-domain books, third-party datasets) is never committed: a download script with a sha256 check
  fetches it on the DGX into an ignored folder.
- The noise sets for the correctors are generated from our evaluation sentences and are never part of the reader's training data at
  Level 1 (spec 4.3).

## The engine

The reader, the `sop` tool and the experiment code are in `tool/` and `experiment/`, imported from the paper's repository
(`PROVENANCE.md`); the changes made here are listed there (portable stars v2, `sop export-web`).
